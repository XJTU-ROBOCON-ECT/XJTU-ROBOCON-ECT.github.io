# 参与文档维护

## 内容原则

1. 只提交确认可以公开的通用知识。
2. 不虚构历史、成绩、成员、素材或参考来源。
3. 示例代码必须与当前比赛工程隔离。
4. 新增链接和事实信息需要核验。

## 公开审查

提交前请确认内容不会帮助外部人员理解当前比赛策略、复现当前机器人，也不包含具体参数、接口、图纸、数据或个人信息。

## 章节模板

新教程统一使用仓库中的 `templates/docs/chapter-template.md`，并补充清晰的标题、描述和侧边栏顺序。
