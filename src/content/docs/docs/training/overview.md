# 培训大纲

每个培训模块将统一维护以下信息：

- Stage 与章节编号；
- 教学目标和前置知识；
- 预计学习时间与培训日期；
- 作业或 Task；
- 经审核的示例代码和推荐资料。

当前 V1 仅建立信息结构。培训时间、例程仓库和课程正文待团队确认后补充。

## 章节标准

每章采用一致结构：What、Why、How、STM32 Context、Example、Common Mistakes、Exercise、Next。这样既方便初学者阅读，也便于维护者持续扩充。
