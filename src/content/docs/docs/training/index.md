# Electronic Control Training

培训路线从基本工具和编程能力出发，逐步过渡到嵌入式系统、执行机构、任务组织和机器人软件体系。

| Stage | 目标 | 主要内容 | 状态 |
| --- | --- | --- | --- |
| 0 | 准备出发 | 环境、Git、AI Agent、资料检索 | 框架已建立 |
| 1 | 编程筑基 | C 语言与基础工程规范 | 框架已建立 |
| 2 | 让单片机工作 | STM32、外设、通信 | 框架已建立 |
| 3 | 让机构动起来 | 电机、传感器、闭环、PID | 框架已建立 |
| 4 | 让机器人完成任务 | 状态机、RTOS、协同与保护 | 框架已建立 |
| 5 | 让机器人跑得更好 | 规划、定位、ROS2、CV | 框架已建立 |

课程日期、学习时间和示例仓库不会硬编码在教程正文中；它们将由可维护的数据结构统一管理，并在确认后发布。

## 使用方式

1. 先阅读每个 Stage 的目标和前置知识。
2. 按章节完成最小例程与练习。
3. 记录问题、验证结果，并用 Git 提交学习成果。
4. 不把比赛代码或内部资料复制到公开示例中。
