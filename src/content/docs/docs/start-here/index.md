# 从这里开始

这套文档是西安交通大学 ROBOCON 机器人战队电控组的**公开学习入口**。它服务于刚接触嵌入式、控制与机器人系统的学习者，也为未来培训内容提供统一结构。

## 你会在这里看到什么

- 从开发环境和 Git 开始的学习路线；
- C 语言、STM32、通信、电机、传感器和控制基础；
- 状态机、FreeRTOS、ROS2 与计算机视觉等进阶方向；
- 经审核后公开的通用教学示例与外部资源。

## 你不会在这里看到什么

- 当前赛季机器人架构、状态机和自动流程；
- 比赛策略、路径、参数、接口表或完整代码；
- 内部故障记录、考勤、成员隐私和未公开资料。

静态网站中发布的内容默认视为公开信息。任何不能公开的资料都应留在有权限控制的内部系统或私有仓库中。

## 下一步

进入[培训体系](/docs/training/)，按 Stage 0—5 了解长期学习路线。当前页面是骨架版本，具体课程将在审核后逐步补充。
